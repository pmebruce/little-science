# 小小科學家 Little Science

給 5–7 歲孩子與家長的中文科學探索 PWA。

## 八個探索主題
- 一口飯的旅行：消化故事、語音與路線互動
- 人體器官探險：大腦、心臟、肺、肝臟、腎臟與胃的合作
- 月亮的光影：日地月位置與可見亮面、觀察筆記
- 潮汐變化：漲退潮、潮差與官方預報入口
- 窗外的天氣：雲雨風、雷電、颱風、彩虹與觀察紀錄
- 光與影：點光源下的影子大小、平面鏡反射與生活任務
- 聲音與振動：音調、大小聲、回音示意與生活任務
- 生活小實驗：火山、鹽水浮蛋、牛奶彩虹與靜電

## 部署至 Cloudflare Pages
框架選 None，不需建置指令，輸出目錄為儲存庫根目錄 `/`，分支 `main`。
所有網站檔案皆位於根目錄，無需 npm、API Key 或伺服器。

## 檔案
`index.html` 為頁面骨架；`app.js` 為親子實驗；`discovery.js` 為消化與天氣；`more-topics.js` 為器官、月相與潮汐。
`style.css` 為介面樣式，`utilities.css` 為已產生的工具樣式。
`sw.js` 提供離線快取，更新網站時請遞增其中的快取版本。

## 使用說明
以 Safari 或 Chrome 開啟網址，可加入主畫面。第一次需連線載入；中文語音依裝置支援，影片連結需連線。
觀察紀錄與照片只保存在目前瀏覽器，不會跨裝置同步，清除網站資料也會刪除紀錄。
月相、潮汐為教學示意，非即時預報。實際海邊活動請查看官方潮汐、天氣與現場公告。

## 內容來源
各單元附中央氣象署、國家教育研究院、教育部及醫院的資料或影片連結。影片為外部連結，著作權屬原作者。
